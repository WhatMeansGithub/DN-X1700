Make your DN-X1600 work with modern Macs

Patch your mixer's firmware so USB audio and MIDI work with the built-in macOS driver: 8 in / 8 out, 24-bit, at 44.1, 48 or 96 kHz. It takes a few clicks, right here in your browser.

Confirmed on a real DN-X1600 by one owner Nothing is uploaded No Denon code hosted here Free and open source

Confirmed by one DN-X1600 owner

This is the same fix that makes the DN-X1700 work on current macOS, confirmed on a real DN-X1700. A DN-X1600 owner has flashed this version on a real unit and reported that it worked. That is one report so far, so please still treat it with care.

Why it works: Denon built the DN-X1600 firmware from the same code as the DN-X1700.

  • The USB description the mixer sends to the computer is byte for byte the same as the DN-X1700's.
  • The faulty sample-rate code is the same, only at different addresses, and so is the updater and its checksum rule.
  • The same checks that the working DN-X1700 firmware passed were run on this one, and all passed: every changed address is checked against the original file, the patched code was run in a simulator at 44.1, 48 and 96 kHz, and the result is verified against a reference build.

If it doesn't work, the most likely outcome is that USB audio on the Mac still doesn't work. The rest of the mixer should be unaffected: the changed code only runs when a computer asks the mixer about its USB audio settings, and the start-up code and the updater are not touched. You can go back by flashing Denon's original X1600FW.BIN the same way.

The real risk is the same as with any firmware update: a power cut while the update is writing (see below). No guarantees of any kind.

Tried it? Please report back, whether it worked or not: more reports help everyone. Questions and discussion: the Engine DJ community thread.

Flashing firmware can permanently destroy your mixer

You do this at your own risk. This project is provided as is, without warranty, and its author accepts no responsibility for bricked mixers or any other damage.

  • The update erases the whole flash chip. If power is lost during the ~30 second write, the mixer won't start again and only an external flash programmer can recover it.
  • Your settings and presets will be reset to factory defaults. Write them down or photograph them first.
  • The fix is tested on one DN-X1700 (macOS 27 on Apple Silicon and Windows) and was reported working by one DN-X1600 owner. The author has no DN-X1600. Technical details.

      Flash it with Denon's updater

      1. Copy X1600FW.BIN to the root of a FAT32 USB stick (MBR partition table; a small stick is safest). Keep the name exactly as it is.
      2. Mixer off. Plug the stick into the rear USB-A port.
      3. Hold MIC2 and DUCKING, switch the mixer on, and keep holding until the display says Ver. UP.
      4. Press UTILITY. The display shows Ver. UP PushClk and scrolls the old and new version (both 2000: the version number doesn't change). To cancel safely, switch the mixer off here: nothing has been written yet.
      5. Press MIDI CLK. The display shows Keep ON Ready, then a percentage. Don't touch anything until it says Finish! (about 30 seconds). Use stable mains power.
      6. Switch the mixer off and on again, then re-enter your settings.
      Then, set it up for the Mac In the Utility settings: set PC/MAC to MAC, USB mode to USB B, and pick the sampling frequency (44.1, 48 or 96 kHz). Power-cycle the mixer, and do so again every time you change PC/MAC or the sample rate. macOS follows the mixer's rate by itself.
      If something goes wrong

      If an error code appears on the display, write it down and don't switch the mixer off straight away: the updater retries by itself. To go back to the original firmware, flash Denon's original X1600FW.BIN the same way. If the mixer shows nothing at power-up after an update, the flash chip needs reprogramming with an external programmer; see the README.

      Tell us how it went

      One owner has confirmed this version; more reports make it more trustworthy. Please open an issue on GitHub (or reply in the thread on the Engine DJ community forum), whether it worked or not, with:

      • Your Mac model and macOS version.
      • Does DN-X1600 show up in Audio MIDI Setup with 8 inputs and 8 outputs?
      • Playback and recording at 44.1, 48 and 96 kHz (power-cycle the mixer after each change).
      • MIDI in your DJ software or DAW.
      • If you have a PC: does Windows in PC mode with Denon's driver still work?

      If it fails on the Mac, the most useful extra is the output of this Terminal command while you plug the mixer in: log stream --predicate 'process == "usbaudiod" OR subsystem CONTAINS "audio"'
