DN-X600 Mac USB fix
DN-X1700 version

Make your DN-X600 work with modern Macs

Patch your mixer's firmware so USB audio and MIDI work with the built-in macOS driver: 8 in / 8 out, 24-bit, at 44.1, 48 or 96 kHz. It takes a few clicks, right here in your browser.

Experimental: not yet tested on a DN-X600 Nothing is uploaded No Denon code hosted here Free and open source

Not tested on a real DN-X600 yet

This is the same fix that makes the DN-X1700 work on current macOS, confirmed on a real DN-X1700. Nobody has flashed it on a DN-X600 yet. You would be one of the first.

Why it should work: Denon built the DN-X600 firmware from the same code as the DN-X1700.

  • The USB description the mixer sends to the computer is byte for byte the same as the DN-X1700's.
  • The faulty sample-rate code is the same, only at different addresses.
  • The DN-X600 is updated differently (Denon's DDJ Updater over USB, with its own CRC-32 file check), and this page builds that check. It was worked out from the updater program and reproduces the checksum of Denon's original file exactly.
  • The same checks that the working DN-X1700 firmware passed were run on this one, and all passed: every changed address is checked against the original file, the patched code was run in a simulator at 44.1, 48 and 96 kHz, and the result is verified against a reference build.

If it doesn't work, the most likely outcome is that USB audio on the Mac still doesn't work. The rest of the mixer should be unaffected: the changed code only runs when a computer asks the mixer about its USB audio settings, and the start-up code and the updater are not touched. You can go back by flashing Denon's original X600FW.BIN the same way.

The real risk is the same as with any firmware update: a power cut while the update is writing (see below). No guarantees of any kind.

Tried it? Please report back, whether it worked or not. Questions and discussion: the Engine DJ community thread.

Flashing firmware can permanently destroy your mixer

You do this at your own risk. This project is provided as is, without warranty, and its author accepts no responsibility for bricked mixers or any other damage.

  • The update rewrites the mixer's flash chip. If power or the USB cable is lost during the write, the mixer may not start again and only an external flash programmer (the chip is an EN29LV160BB) can recover it. Denon's own instructions say the same.
  • Your settings may be reset to factory defaults. Write them down or photograph them first.
  • The fix is tested on one DN-X1700, with macOS 27 on Apple Silicon and with Windows. It is not tested on a DN-X600. Technical details.

      Flash it with Denon's updater

      The DN-X600 has no USB stick port. It is updated from a computer with Denon's DDJ Updater, which is in the zip from step 1 (Windows: DDJUpdater-2.0.msi). The Mac version of the updater in that zip is too old to run on current macOS, so use a Windows PC.

      Option A: flash straight from this page (Mac or Windows) experimental

      Needs Chrome or Edge (Safari and Firefox can't talk to USB HID devices). No Denon software needed. This sends the file to the mixer using the same messages as Denon's updater, which were read out of that program but have never been run against a real DN-X600. Nothing is written to the mixer's flash until the final Execute step; you can stop before that.

      This browser can't do it. WebHID is missing. Open this page in Chrome or Edge, or use Option B below.
      1. Mixer off, USB cable to the computer, then hold DUCKING and SELECT and switch on until the display shows UP.
      2. and pick the Denon device in the browser's list.
      3. Firmware file
        No file yet. Add Denon's firmware in step 2, or choose a file here.

        Once Denon's file is loaded (in step 2, or with the button above: the zip as downloaded, or X600FW.BIN) you get both versions to choose from. An already-patched file from this page is accepted too. Anything else is refused. First time? Send Denon's original first: it changes nothing if everything works.

      Option B: Denon's DDJ Updater (Windows)

      1. Install DDJ Updater on the Windows PC and start it. It says Waiting.
      2. Mixer off (rear switch). Connect the USB cable from the mixer's USB B port to the PC.
      3. Hold DUCKING and SELECT, switch the mixer on, and release when the display shows UP. The USB indicator is blue. If Windows asks to install a driver, install it from the unit. To cancel safely, switch the mixer off here: nothing has been written yet.
      4. Drag the patched X600FW.BIN into the DDJ Updater window (or File > Open), click Load, then OK. If it says the file is invalid or has a CRC error, stop and tell us.
      5. Click Execute. Don't touch anything and don't unplug the cable or switch the mixer off until the display says donE. If it shows FAIL, click Execute again. Use stable mains power.
      6. Switch the mixer off and on again.
      Then, set it up for the Mac The DN-X600 has no PC/MAC menu: it is a key combination, and it can't be changed while a computer is connected. Unplug the USB cable, hold EFX CUE and press BEAT ◀▶ to enter the OS setting mode, choose Mac OS with BEAT ◀▶, and press TAP to confirm. (The factory default is PC.) Power-cycle the mixer, then connect it to the Mac. The fix only applies in Mac mode.
      If something goes wrong

      If the display shows FAIL, click Execute again. Don't switch the mixer off in the middle of an update. To go back to the original firmware, flash Denon's original X600FW.BIN the same way. If the mixer shows nothing at power-up after an update, the flash chip needs reprogramming with an external programmer; see the README.

      Tell us how it went

      This is how the DN-X600 version stops being experimental. Please open an issue on GitHub (or reply in the thread on the Engine DJ community forum), whether it worked or not, with:

      • Your Mac model and macOS version.
      • Does DN-X600 show up in Audio MIDI Setup with 8 inputs and 8 outputs?
      • Playback and recording at 44.1, 48 and 96 kHz (power-cycle the mixer after each change).
      • MIDI in your DJ software or DAW.
      • If you have a PC: does Windows in PC mode with Denon's driver still work?

      Want to help most? A USB capture of Denon's own updater lets us check this page's browser flasher against the real thing. Step-by-step guide for testers (Wireshark + USBPcap, Windows).

      If it fails on the Mac, the most useful extra is the output of this Terminal command while you plug the mixer in: log stream --predicate 'process == "usbaudiod" OR subsystem CONTAINS "audio"'
